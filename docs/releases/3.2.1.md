# Soduto 3.2.1 (36)

The device menu now has a clearer layout, colored device icons, connection status, and reported battery/network details. It also adds a separator above **Reconnect All Devices** in Diagnostics.

## Changes

- **Build compatibility:** explicitly marshal device-list refresh onto the main actor for older SDKs, preserving synchronous main-thread updates. A regression reproduces the previous compiler failure and checks background callbacks.
- **Device menu:** show device-type icons even when a peer has no battery report. Add native Connected/Offline subtitles, sort connected devices first, and keep existing device submenus and keyboard navigation. On macOS 27, request visible menu icons explicitly. On macOS 14.0–14.3, status uses a single-line fallback.
- **Menu organization:** group Device Dashboard, Preferences, and About together; place Launch at Login and Fork Releases below them. Diagnostics remains directly above Quit.
- **Diagnostics:** visually separate recovery from log-writing actions. Logging remains off by default, and Reconnect All Devices remains available when logging is off.
- **Connection improvements and bugfixes:** retain sleep/Wi-Fi recovery, equal-network-path filtering, protocol 7/8 pairing, certificate verification, clipboard freshness, and legacy Keychain signing fixes.
- **Clipboard:** text, images, and one regular file up to 50 MiB with compatible peers. Image/file sync needs `kdeconnect.clipboard.file`. Official GSConnect v74 supports text only; see the [GSConnect fork](https://github.com/hidoba/gnome-shell-extension-gsconnect/tree/hidoba) for image/file clipboard work. Linux paste behavior depends on the application and desktop integration; Ubuntu GNOME/Wayland image/file sync still needs real-device validation.
- **Build workflow:** manual GitHub Actions builds avoid duplicate push/PR jobs, keep test and build logs even on failure, and use pinned Node 24 Actions.
- **Website:** [soduto.hidoba.com](https://soduto.hidoba.com) has illustrated previews, download links, compatibility notes, and the latest app commit date. Its source lives on the separate [`codex/website`](https://github.com/hidoba/Soduto/tree/codex/website) branch.

## Install

Download `Soduto-3.2.1-36-macos-universal.zip` and its `.sha256` file. Verify the download, quit Soduto, and replace the app in Applications.

```sh
shasum -a 256 -c Soduto-3.2.1-36-macos-universal.zip.sha256
```

Requires macOS 14 or newer; supports Apple Silicon and Intel. This is an ad-hoc-signed, unnotarized development build. Existing pairings and preferences are preserved. Replacing the app may require normal Keychain approval. Updates are manual through Fork Releases on GitHub.

## Validation

122 automated checks pass: 20 reliability tests, 60 clipboard scenarios, 17 pairing/transport scenarios, 9 diagnostics/menu scenarios, and 16 real Keychain/mutual TLS tests. A separate regression verifies 600 signatures using a legacy key in a temporary keychain. The universal Release app and extensions build successfully, and the packaged app passes strict signature verification on both architectures.

The new device presentation was also rendered in a native AppKit menu on macOS 27 using production code. Exact spacing and material follow the macOS appearance. Automated clipboard/transport checks do not establish end-to-end compatibility with a physical Ubuntu peer.
